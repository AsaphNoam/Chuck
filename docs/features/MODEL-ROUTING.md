# Model routing

This is the current model policy for repository work, delegation, and the finding
recommendations in workflow §7. Select only models actually registered or advertised
in the active environment. A familiar name in these instructions does not establish
availability or authorize an invented model identifier.

The user's defaults are Codex Sol 6.1/6.2 and Claude Opus 5.5. Use an available
default for consequential implementation, ambiguous investigation, and integration
judgment. For easy independent work with clear acceptance criteria, choose the
cheapest advertised model capable of delivering it reliably. Do not assume a
historic Luna, Terra, Sonnet, or any other selector remains available.

The table defines the current recorded recommendation. Copy the complete phrase
after `**Fix model:**` once per finding unit, choosing its most difficult open fix.
Severity does not determine complexity. Historical recommendations already recorded
in the handoff remain readable; they do not override this policy for new work.

| Band | Recommendation |
| --- | --- |
| trivial/easy | trivial/easy — cheapest advertised capable model. |
| medium | medium — Codex Sol 6.1/6.2 or Claude Opus 5.5. |
| difficult | difficult — Codex Sol 6.1/6.2 or Claude Opus 5.5. |

Resolve the recommendation to an available model before starting. If a preferred
model is unavailable, choose an advertised alternative by required capability,
expected total cost, and verification risk; explain a material substitution.
When evidence conflicts or verification fails, carry forward useful evidence and
reassess the brief, capability, and effort instead of repeatedly retrying an
unsuitable model. Reserve the highest effort for a concrete expected benefit.

Workflow procedures own unit selection, finding classification, delegation
requirements, and independent closure checks. This map only owns model selection.
