The original snapshot passed 1,425 UI tests. The rebased snapshot passed all 1,421 using
`npm test -- --maxWorkers=3 --minWorkers=1`. A focused concurrent run failed two SSE tests.
Limiting the SSE run to one worker passed 38 checks. Delaying only the `sse.ts` transform by six
seconds then reproduced the failure pair, first the watchdog test's import timeout and then the
revision-discard assertion on the stale store. The timed-out import remains live across test
module reset. This is an open test isolation finding under TS-06.R35, with no product lifecycle
failure established by those two assertions.

`npm run build` passed the 48 presentation checks, type checking and Vite production build with
copied dependencies. The initial attempt used a symlink to the checkout's dependencies and hit
TS2742 module path resolution; copying dependencies into the snapshot resolved it. The tagged
`make build` passed with that regenerated UI embedded in the isolated tree. Host Go 1.26.6,
Node 22.23.1, darwin/arm64. The build emitted Vite's chunk-size warning. `make test` passed both
Go variants with loopback. A separate 12-test `sqlite_fts5` run passed across server, runtime
and state for Switch rollback, journal-close waits, stopped/running quota continuation,
runtime-budget admission and pending-release accounting. `make check-specs` passed on the
review state.

Each ready task in a list response performs a config read and a claim-count query. A synthetic
in-memory SQLite probe ran that exact query 200 times with 200 ready tasks and 10 active claims.
The median of five runs rose from 6.5 ms with 1,000 finished tasks to 53.5 ms with 10,000.
`EXPLAIN QUERY PLAN` reported a table scan for the claim count. This measures that SQL predicate
in isolation. End-to-end list latency, background fan-out, RSS and realistic workload size remain
unmeasured. Browser/device, native authentication, credentialed providers and hosted release
evidence keep their existing gates.
